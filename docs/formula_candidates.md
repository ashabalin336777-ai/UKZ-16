# Formula Candidates — research-v0.2

> **Важно:** веса и субформулы ниже — **исследовательский scaffold**, не клинически утверждённые константы. Любой перенос в практику требует валидации R1–R4.

## Интегральный индекс

\[
HEALTH\_ID = 0.60 \cdot hBody + 0.25 \cdot hMental + 0.15 \cdot hSocial
\]

Считается только если hBody, hMental и hSocial одновременно имеют статус `derived`. Сумма точная: веса не перенормируются. Иначе `health_id.value = null`.

## hBody (scaffold)

Нормализованный балл 0–1 только из измеренных АД и пульса. ИМТ в hBody не входит.

- Нет `height_cm` или `weight_kg` → отдельные результаты `bmi` и `ap_baevsky`: статус `missing`, причина `missing_height_weight`
- Полный АП Баевского считается только при росте, весе, возрасте, ЧСС и АД. Пороги классического АП не применяются
- Неизвестные единицы / битый протокол → компонент `missing` с причиной `quality_blocked`

## hMental (scaffold)

- Без валидированной психометрии → `not_calculable: no_validated_psychometrics`
- Голос / SVS — **вне Phase 1**, всегда experimental (не реализовано)

## hSocial (scaffold)

- Без утверждённых метрик → `not_calculable: no_validated_social_metrics`
- Посещаемость ≠ мотивация

## Персональные коридоры

Baseline строится только по **предыдущим** уникальным датам с `quality=ok`. Текущая точка **исключается**.

## Persistence

Считается по **уникальным календарным датам** отклонений, не по числу попыток в один день.
