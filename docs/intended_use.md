# Intended Use — HEALTH_ID (УКЗ-16)

## Research use only

Система предназначена **исключительно для исследовательской** воспроизводимой оценки, контроля качества данных и поэтапной клинической валидации интегрального индекса здоровья **HEALTH_ID** на данных периодических медицинских осмотров (ПрМО).

## Что система делает

- Версионированный расчёт HEALTH_ID (scaffold `research-v0.2`).
- Проверку происхождения, единиц, полноты и протокола измерений.
- Построение персональных коридоров без утечки текущей точки в baseline.
- Классификацию сигналов: острое отклонение / устойчивое повторное отклонение / хроническое (только из МИС/ЭМК).
- Полный explanation contract для медицинского работника.
- Clinical review (human-in-the-loop): pending / confirmed / rejected.
- Model governance: model card, журнал версий, тесты, drift alerts.

## Что система не делает

- Не ставит диагноз.
- Не назначает лечение и не выдаёт допуск к работе.
- Не передаёт индивидуальный HEALTH_ID, SVS, анкеты, витальные показатели или диагнозы работодателю.
- Не выполняет скрытую импутацию пропусков.
- Не использует HRV / rPPG / голос как диагностические признаки в Phase 1 (вне scope).
- Не выполняет автоматическое обновление модели в проде при drift.

## Контуры доступа

| Роль | Доступ |
|------|--------|
| researcher | расчёт, результаты, model card, timeline |
| medical_worker | clinical review |
| auditor | audit / journal (read-only) |

Роль работодателя к индивидуальному HEALTH_ID **запрещена**.
